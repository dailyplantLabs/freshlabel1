# FreshLabel — 미개봉 선입선출(FIFO) & 소분·개봉 라벨 원터치 출력 시스템

식품위생법상 의무 항목이자 구청 위생점검 단속 1순위인 **소분·개봉 식재료 소비기한 라벨 표시**와 **미개봉 완제품의 로트(Lot)별 선입선출(FIFO) 재고 관리**를 태블릿 한 화면(좌/우 2분할)에 통합한 단독형(Stand-alone) 웹 앱(PWA)입니다.

---

## 1. 실행 방법

1. **즉시 실행**: [`index.html`](./index.html) 파일을 크롬/엣지 브라우저로 바로 열어서 사용할 수 있습니다.
2. **로컬 PWA 서버 실행 (Web Bluetooth 및 태블릿 Wi-Fi 접속용)**:
   - [`start_freshlabel.bat`](./start_freshlabel.bat)을 더블클릭하면 `http://localhost:8090`으로 자동 실행됩니다.

---

## 2. 핵심 구현 기능

### ① 좌측 패널: 미개봉 재고 & 소비기한 (선입선출 FIFO)
- **로트(Lot)/도래일자별 자동 분리 및 정렬**: 같은 품목이라도 소비기한이 빠른 순서대로 상단에 배치됩니다.
- **신호등 컬러 인덱스**: `위험(D-3 이내)`, `주의(D-7 이내)`, `여유(D-7 이상)` 배지 표시.
- **원터치 연계 (`[-1팩 개봉 + 라벨출력]`)**:
  - 미개봉 재고에서 `[-1팩 개봉 + 라벨출력]` 버튼을 누르는 순간 미개봉 수량이 1 차감되고, 우측의 해당 품목 소분 라벨(`개봉 후 +N일` 자동 계산)이 즉시 발행되며 냉장고 소분 타이머에 자동 등록됩니다.
- **선입선출(FIFO) 순서 위반 방지 가드**:
  - 알바생이 실수로 먼저 만료되는 로트를 놔두고 뒤에 있는 새 로트의 개봉 버튼을 누르면 경고 모달이 작동하여 폐기 손실을 예방합니다.
- **바코드(식약처 API 규격) + 소비기한 OCR 초고속 입고 시뮬레이션**:
  - `[+ 새 박스/팩 입고 등록]` 모달에서 바코드·OCR 스캔 시뮬레이션을 통해 1초 만에 품목과 유통기한을 입력할 수 있습니다.

### ② 우측 패널: 개봉·소분 라벨 원터치 출력 & 활성 타이머
- **소분용 프리셋 버튼 그리드**: `우유 개봉(+3일)`, `생크림 소분(+5일)`, `바닐라시럽(+30일)`, `레몬슬라이스(당일폐기)` 등 원하는 품목을 **터치 1번(소요시간 2초)**으로 출력합니다.
- **식품위생법 점검 완벽 대응 라벨 규격**:
  - `[품명]`, `[소분일시]`, `[소비기한]`, `[담당자]`, `[보관방법]` 및 고유 라벨 번호(`#L-105`)가 표기된 방수 감열 스티커 미리보기 및 실제 인쇄(`@media print` 58mm×40mm 전용 규격) 지원.
- **Web Bluetooth API & 감열 프린터 사운드 피드백**:
  - BLE 영수증/라벨 프린터 연동(`printer.js`) 및 출력 시 직관적인 프린터 모터·비프음 피드백 제공.

### ③ 하단 바: 일일 마감 폐기 대상 알림 & ROI 리포트
- 오늘 밤 폐기해야 하는 개봉·소분 용기(`개봉 생크림 1통`, `레몬 슬라이스 1통` 등)를 하단 고정 바에 상시 표시하고 원터치 `[폐기 완료]` 체크를 지원합니다.
